# Processing Notes — Multi-Party RDH in Ciphertext Binary Images (Chen 2025)

- **Paper:** Bing Chen, Jingkun Yu, Bingwen Feng, Wei Lu, Jun Cai, IEEE Signal Processing Letters, vol. 32, 2025
- **Reproduction tier:** B
- **Status:** Completed (full reproduction)

## What was reproduced
(1) Genuine (2,2) visual-cryptography sharing with verified lossless XOR reconstruction (0 error). (2) Reversible binary-image embedding via block-value histogram shifting with exact recovery.

## Reproduced vs reported
VC sharing and reversible binary embedding reproduced. The **multi-hider embedding protocol** is represented by single-share embedding (stated openly).
