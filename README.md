# Multi-Party RDH in Ciphertext Binary Images via Visual Cryptography (Chen 2025)

Reproduction work for Multi-Party RDH in Ciphertext Binary Images via Visual Cryptography. Original paper by Bing Chen, Jingkun Yu, Bingwen Feng, Wei Lu, Jun Cai, IEEE Signal Processing Letters, vol. 32, 2025.

It works on plain black and white images, where any pixel flip is easy to spot, by mapping blocks so the change stays hidden and reversible.

I rebuilt the working core of the method and ran it on real test images. Where the paper leaned on a piece I could not recreate in this workspace, I used a clearly labelled stand in and wrote down exactly what and why in the notes.

## Running it

Everything runs with plain Python and a handful of common libraries. From this folder:

```bash
cd source_code
python3 run_experiment.py       # runs the method, writes metrics and figures
python3 build_deliverables.py   # rebuilds the IEEE report and the slides
```

You need numpy, scipy, matplotlib, pillow, python-docx and python-pptx. Install them with `pip install numpy scipy matplotlib pillow python-docx python-pptx`. The report is exported to PDF with headless LibreOffice, so that has to be on the machine if you want the PDF rebuilt.

## A note on honesty

All the numbers you see are generated by running the code. The paper's own figures appear only where a row is labelled reported. Where the exact image set or an unstated hyperparameter differs from the paper, the absolute figures can move a little, but the behaviour and the reversibility hold. The specifics for this paper are in `processing_notes.md`.
